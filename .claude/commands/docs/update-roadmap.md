# Claude 명령어: Update Roadmap

완료된 작업을 **루트 `ROADMAP.md`**에 체크하고 진행 상황을 업데이트합니다. (docs/ROADMAP_v1.md는 정본 기획 문서이므로 수정하지 않습니다.)

## 사용법

```
/docs:update-roadmap
```

## day3box ROADMAP.md 구조 (이 형식을 기준으로 동작)

- 전체 Task: **001~009 (9개)**, Phase 1~5로 그룹화
- Task 제목: `#### Task 00X: 작업명` (+ 현재 우선순위 Task에만 ` - 우선순위`)
- 수락 기준·테스트 체크리스트: `- [ ]` 체크박스 리스트
- Phase 제목: `### Phase N: 제목` (완료 시 ` ✅` 추가)

## 프로세스

1. 루트 `ROADMAP.md` 읽기
2. 미완료 Task 목록 표시
3. "어떤 Task를 완료했나요? (예: 001 또는 001,002)" 질문
4. 해당 Task 업데이트:
   - Task 제목: `#### Task 00X: 작업명 - 우선순위` → `#### Task 00X: 작업명 ✅ - 완료`
   - 해당 Task의 수락 기준·테스트 체크리스트: `- [ ]` → `- [x]`
5. **다음 우선순위 지정**: 완료된 Task 다음 번호의 미완료 Task 제목에 ` - 우선순위` 추가
   - **"- 우선순위" 표시는 로드맵 전체에서 항상 정확히 1개**여야 함 (전부 완료 시 0개)
6. Phase 상태 확인: Phase 내 모든 Task가 ✅면 Phase 제목에 ` ✅` 추가
7. 변경 사항 요약 출력

## 업데이트 규칙

### Task 완료 체크

**Before:**

```markdown
#### Task 002: Brain dump 패널 구현 - 우선순위

**수락 기준**
- [ ] 항목 추가/삭제가 즉시 화면에 반영되고 DB에 저장된다
```

**After:**

```markdown
#### Task 002: Brain dump 패널 구현 ✅ - 완료

**수락 기준**
- [x] 항목 추가/삭제가 즉시 화면에 반영되고 DB에 저장된다
```

### 주의사항

- Task 번호는 3자리 형식 (001~009)
- 이미 완료된(✅) Task는 건너뜀
- **수락 기준이 실제로 충족되지 않은 항목은 체크하지 않는다** — 사용자에게 미충족 항목을 알리고 확인받는다
- Task 009의 "실사용 추적" 체크박스(1~3일차)는 실제 실사용 일수만큼만 체크
- v1 이후 "착수 금지" 섹션은 절대 Task로 분해하거나 체크하지 않는다
- 여러 Task 동시 완료 지원 (예: 002,003)

## 출력 예시

```
✅ Task 002 완료 처리했습니다.
→ 다음 우선순위: Task 003 (TOP 3 선정 및 소요시간 입력 구현)
📊 진행 상황: 2/9 Tasks 완료 (Phase 1 ✅, Phase 2 진행 중)
```
