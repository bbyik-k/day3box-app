- **일반(비 TOP3) 할 일도 배치 가능** — 소요시간 미지정이면 기본 30분, 조정은 리사이즈로
- 카테고리 팔레트 전면 유채색화 (회색→보라, 남색→초록) — TOP3(유색)와 일반 블록(무채색 회색 바)이 색으로 구분되고, 승격 시 미사용 색이 자동 지정된다. 이월(moved) 표시는 중립 회색 유지
- 소요시간 ↔ 블록 높이 **양방향 동기화** (분 수정 → 블록 리사이즈, 리사이즈 → 분 갱신)
