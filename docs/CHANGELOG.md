## 2026-07-31

### 고정 시간 (Task 012)
- 그리드 빈 영역을 **드래그해 "확보한 시간"(식사·이동·휴식·약속)을 직접 생성** — 고스트 미리보기(하단에 소요시간·시각) → 이름 입력 → 생성. 드래그 중에만 10분 눈금 표시
- `tasks.kind`('task'/'fixed') 구분: 고정 시간은 **brain dump에 나타나지 않고 그리드에만 존재** — TOP3 승격·이월 불가, 기록 집계 제외 ("할 일"과 "확보한 시간"의 분리, 브리프 D2)
- 1b 시각: 막대 없음 + 본문 옅게 + 옅은 외곽선. 그리드 범례를 3위계(오늘의 셋/나머지 할 일/확보한 시간)로 교체
- 마지막 블록 삭제 시 고정 task도 함께 삭제 (유령 행 방지)

### 블록 분할 (Task 011)
- 긴 작업이 점심 등으로 끊길 때 **같은 task를 여러 블록으로 배치** (1 task : N blocks — 스키마는 원래 지원, UI 해제)
- **배치 클릭 = 미배치 잔량(계획 총량 − 배치 합)을 다음 빈 슬롯에** — 리사이즈로 줄인 뒤 재클릭하면 잔량이 배치된다 (별도 분할 UI 없음)
- 분할 블록은 같은 색·제목 + `1/2`·`2/2` 표기 + 잘린 변(첫 조각 하단 잘림, 뒤 조각 상단 파선·들여쓰기)
- TOP3 카드에 배치량 표시: `총 180분 중 30분 배치됨` / `미배치` / 전량 시 `180분 배치됨`
- PRD §2.2 분할 UI v2 → v0 이동 (실사용에서 매일 발생·우회로 없음 확인)

### 시간 체계 정비 (Task 010)
- **스냅 15분 → 10분** — 시작점과 길이의 단위를 일치시켜 블록 끝점이 항상 격자 위에 온다 (D5)
- **그리드 04:00 ~ 익일 03:00** — 하루 경계 04시: 새벽 3시까지는 전날의 하루, 자정 이후 블록(00~03시)이 전날 그리드 하단에 표시 (D9)
- **소요시간 자유 입력 제거** → 칩(30/60/90/120/180) + ±10 스테퍼. 10분 배수 DB 제약 (D6 — "가짜 정밀" 교정)
- **est↔블록 비동기화** — 리사이즈가 분을 갱신하지 않고 분 수정이 블록을 건드리지 않음. est=계획 총량, 블록=실제 배치 ([ADR-0002](adr/0002-est-block-desync.md) — 7/29 양방향 동기화 롤백, 블록 분할의 전제)
- 기존 데이터 10분 격자 라운딩 마이그레이션 (겹침 0건 사전 확인)

### 낙관 반영 전면 확장 (Task 009.5, `7c7068e`)
- 색·소요시간·배치·삭제·이월 등 모든 조작이 서버 응답을 기다리지 않고 좌측 카드와 우측 그리드에 **즉시(50ms 내) 동시 반영**된다
- 배치 미리보기 슬롯 = 서버 확정 슬롯 (슬롯 탐색 로직을 서버·클라이언트가 공용)
- 소요시간 변경이 겹침·그리드 범위 초과를 유발하면 즉시 에러로 거부 (서버 검증은 백스톱 유지)
- 구조 결정 기록: [ADR-0001 낙관 스토어 단일화](adr/0001-optimistic-store-unification.md)
