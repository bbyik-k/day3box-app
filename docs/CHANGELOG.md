### v0 마지막 개선 — 입력 지연·부분 배치·탭 분리·초과 표시 (Task 016, Brief 006 D16~D19)

**v0 성공 기준(연속 3일 실사용 7/31·8/1·8/2) 통과.** 이 사이클로 v0 개선을 종료하고 v1(사진) 판단으로 넘어간다.

- **task 추가가 즉시 이어진다** (D16) — 항목을 추가하면 입력창이 서버 응답(~1초)을 기다리지 않고 곧바로 비워져 연속 입력이 끊기지 않는다. 원인은 낙관 반영 누락이 아니라 form action이 서버 왕복을 붙잡아 React 19의 자동 폼 리셋이 밀리는 구조 — `onSubmit` 수동 초기화로 전환 (실측 566ms → 0~1ms)
- **빈 구간에 들어갈 만큼만 부분 배치** (D17) — 잔량 140분을 60분 빈 구간에 드롭하면 60분 블록이 생기고 잔량 80분이 남는다. 잘림은 드래그 중 고스트 크기와 `60분 · 남은 80분` 라벨로 미리 보인다 (보이는 크기 = 저장 크기). 최소 크기 제한 없음, 그리드 끝(익일 03:00)도 동일 규칙. 클릭 배치는 고스트가 없어 제외 (기존 "잔량 전체 슬롯 탐색" 유지)
- **블록 클릭이 탭을 바꾸지 않는다** (D18) — 선택은 "만지겠다"이지 "기록하겠다"가 아니다. 탭 이동은 탭 버튼으로만, 선택→기록 탭 편집 카드 연동은 유지 (D14 표식 순환 확정 이전의 잔재 정리)
- **계획 총량 초과 시 두 숫자 병기** (D19) — 배치 합이 계획을 넘으면 `210분 / 계획 180분`. 초과는 오류가 아니므로(ADR-0002) 경고색·아이콘 없이 옅은 강조만, 줄이면 `배치됨`으로 자연 복귀. "추정이 30분 짧았다"는 학습 신호가 된다

### 드래그 마감·클릭 배치 규칙·제목 인라인 편집 (Task 015, Brief 005 D11~D15)
- **커서 추종 드래그 프리뷰** — 잡는 순간부터 `이름 · N분` 카드가 커서를 따라오고, 그리드에선 스냅 고스트와 동시 표시 (리스트 구간에서 피드백이 끊기던 미완성 마감)
- **클릭 배치 = 마지막 블록 뒤** — 예측 가능. 안 들어가면 빈 슬롯 폴백 + 배치 위치로 스크롤 알림
- **행/카드 전체 드래그**(임계 5px) + 역할 분리: 손잡이 클릭=배치 / **제목 클릭=인라인 편집(신규)** / 배지=토글. 편집은 리스트·TOP3 카드·그리드 블록 세 곳 공통 규칙(Enter/blur 저장·Esc 취소·빈 값 원복)
- **블록 상태 표식 클릭 = 상태 순환** (계획→완료→부분→이월)
- 배치 행 농도 0.72 → 0.5 / TOP3 카드에서도 드래그 배치
- 미결 1(est↔블록 비동기) **확정 승격** — 이 사이클로 개선 닫음, v1 판단 게이트 진입

### Brain dump 행 재설계 + 드래그 배치 (Task 014, Brief 004 D9)
- **체크박스 제거** — 완료 통념과 충돌하고 저빈도 동작(TOP3 승격)이 진입점을 차지하던 문제 해소. 행 = [⠿ 손잡이 | 색 막대(TOP3만 컬러) | 이름 | 호버 힌트 | TOP 3 배지 토글]
- **손잡이 드래그 → 원하는 시각에 직접 배치** (드롭 지점 = 시작 시각, 10분 스냅, 가장자리 자동 스크롤, 겹침 위치는 고스트가 거부 표시). 손잡이 클릭 = 다음 빈 슬롯 (드래그를 강요하지 않는다)
- 드롭 길이 = est ?? 30분 (위치 지정만 — 길이 조절은 리사이즈, D6 역할 분담). 재드래그 = 잔량 배치, 전량 배치 행은 드래그 불가 (이동은 그리드에서)
- 배치 여부는 **밝기 한 채널**(0.72)로만 — 자리 이동 없음(입력 순 = 생각의 순서 보존), 헤더에 "N개 남음"
